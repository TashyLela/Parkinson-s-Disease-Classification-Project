Data Acquisition Instructions

Dataset: Parkinson's Disease Classification
The dataset used in this project is sourced from the UCI Machine Learning Repository.

How to Download:
1. Visit the UCI link: [Parkinson's Disease Classification Dataset](https://archive.ics.uci.edu/dataset/174/parkinsons)
2. Click on the "Download" button to get the `parkinsons.data` file.
3. Place the downloaded file in this `/data` folder on your local machine.

Important Note:
As per the project requirements, the raw `.data` or `.csv` files are NOT included in this GitHub repository to keep the repository size manageable and follow data distribution guidelines. `.gitignore` is active to prevent accidental uploads of these files.
