Machine Learning 2 Project: Unsupervised Learning Techniques



Project Description

This project applies unsupervised learning techniques (K-Means, Hierarchical Clustering and DBSCAN) to the Parkinson's Disease Classification dataset from the UCI Machine Learning Repository. The goal is to design a reproducible pipeline for preprocessing, clustering and evaluation.



Dataset Source

Name: Parkinson's Disease Classification

Source:\[UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/174/parkinsons)



Setup and Requirements

To run this project, the following libraries are needed:

\- pandas

\- scikit-learn

\- matplotlib

\- seaborn

\- ucimlrepo



Install them using:

`pip install pandas scikit-learn matplotlib seaborn ucimlrepo`



How to Run

1\. Clone the repository.

2\. Open the Jupyter Notebook located in the `/notebooks` folder.

3\. Run the cells sequentially to see the pipeline from data cleaning to evaluation.
